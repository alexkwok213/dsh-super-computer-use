# 本地模型与 CU 加速评估

日期：2026-10-30。本文是方案评估，不代表已安装模型、运行基准或证明速度提升。

## 结论

用户提供的 MiniCPM-OCR 项目值得做 OCR 对照，但 **Jev 是 OCR 结果评分模型，不是电脑操作模型，也不负责生成识别文本**。推荐先量化 CU 端到端瓶颈，修复真实截图，再在隔离测试集对比系统 Vision OCR、MiniCPM-OCR 1.0 和一个有 GUI 视觉定位能力的轻量模型。将小模型的输出作为建议，仍由现有动作安全检查执行；复杂或失败时升级给上层模型。无需先引入 Jev；只有实际发现 OCR 高风险误识别，并且过滤收益超过额外延迟时才考虑。

## 外部项目事实

- [MiniCPM-OCR](https://github.com/OpenBMB/MiniCPM-OCR)：1.0 是 1.3B 文档 OCR 模型，处理图像/PDF、表格等；Jev 是独立 2B 评价模型。项目代码、文档和权重声明 Apache-2.0。适用场景和许可证以各版本页面为准。
- [Jev 文档](https://github.com/OpenBMB/MiniCPM-OCR/blob/main/docs/minicpm_ocr_jev_en.md)：接收图像区域及已有 OCR 候选文本（并使用该文本渲染图），评分 0–1；用于比较或复核候选。分数不是经过通用校准的正确概率，不能直接当成安全点击依据。官方未宣称它输出 GUI 点击动作。
- [1.0 文档](https://github.com/OpenBMB/MiniCPM-OCR/blob/main/docs/minicpm_ocr_1dot0_en.md)：官方文档处理测试在 RTX 5090 上报告 1.217 页/秒、P95 2.1 秒、P99 3.8 秒；不是 M1 Max 上 GUI 截图延迟。README 和模型指南未明确 GUI 场景的逐词坐标输出，需在实际接口验证。
- [llama.cpp 部署](https://github.com/OpenBMB/MiniCPM-OCR/blob/main/docs/llamacpp_deploy.md)提及 Apple Silicon 的 Metal；[Ollama 部署](https://github.com/OpenBMB/MiniCPM-OCR/blob/main/docs/ollama_deploy.md)列出的主模型、视觉投影和 draft 权重合计约 2.04 GB，仅是文件大小，不是运行内存。环境、权重版本、性能需本机验证。
- [Qwen3-VL-2B-Instruct 模型卡](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct)声称支持 GUI 元素理解和空间定位，Apache-2.0；可作为 GUI 小模型候选，具体坐标格式、中文 macOS 界面准确率和本机速度均未测试。不要直接拿文档 OCR 的成绩代表 GUI 操作能力。

## 现有系统与限制

- 本机 M1 Max、64 GB 统一内存；具备探索本地推理的硬件条件，但模型的 RAM 使用、温度、延迟和准确率尚未实测。当前 shell 未发现 `ollama`、`llama-server` 或 `mlx_lm.server` 可执行文件（仅代表当前 PATH）。
- 项目是 MCP 工具服务器，使用何种模型和模型推理是在外部宿主；添加 OCR 后端不自动改变宿主的模型选择或减少模型回合数。`mcp/server.py` 的 OCR 优先 AX 查找，之后截图并通过 Apple Vision OCR；已有 `batch` 顺序执行工具，适用于步骤明确的场景，并非自治规划器。
- 真实截图在当前会话曾失败；截图修复和内容验证是任何视觉模型实验的前提。用户的剪映素材任务中，02 之前已导入，不能以不确定批量动作破坏或重复导入来压测。

## 推荐架构

1. **任务层**：复杂目标由上层模型拆解；支持保存可重复、条件明确的动作流程。对于前置条件已验证的流程，由本地执行器顺序执行并在关键状态判断，不必每点一次都重新请求大模型。
2. **感知层**：优先 AX 获取目标、焦点及状态；需要图像识别时再用截图。Apple Vision 给带坐标的文字候选；MiniCPM-OCR 可做文档类识别试验，是否输出稳定的 GUI 坐标待测；GUI VLM 可对难以通过 AX/OCR 定位的元素给候选坐标。
3. **执行层**：坐标/操作要绑定窗口与进程，执行现有焦点、遮挡、模态、安全输入保护；验证目标和动作后的实际状态。小模型建议不得直接绕过安全检查；不可确认时中止或升级。
4. **分级处理**：明确规则或 AX 可解决的动作走快速路径；图像理解交给本地模型试验；歧义、异常和复杂跨应用任务才请求上层模型。不要假定小模型一定更快或正确。
